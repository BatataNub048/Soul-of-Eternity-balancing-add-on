# Boss and encounter research

[Encounter catalogue](encounter-catalogue.json) records the mod namespace, internal NPC name, snapshot-local numeric type and observed boss flag. [Encounter performance summary](encounter-performance-summary.csv) contains aggregate measurements from earlier local playtests.

The catalogue includes some encounter phases and segments as separate NPC entries. Boss flags also omit encounters tracked through other mechanisms. The baseline pins Boss Checklist and retains its configuration preset. The planned audit will compare the catalogue with Boss Checklist entries for bosses, minibosses, events, and rare enemies. The existing data is a starting point for that audit.
